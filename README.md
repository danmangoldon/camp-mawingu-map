# Camp Mawingu Map

Production-ready Mapbox map for the Camp Mawingu intranet.

## GitHub Pages

Repository:

`https://github.com/danmangoldon/camp-mawingu-map`

Published page:

`https://danmangoldon.github.io/camp-mawingu-map/`

## Upload

Upload these files directly to the repository root:

- `index.html`
- `interact-iframe.html`
- `README.md`

Do not upload the ZIP itself.

## Enable GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

## Interact embed

Paste the contents of `interact-iframe.html` into an Interact HTML widget.

## Map configuration

Camp Mawingu coordinates:

- Latitude: `-1.3668933792826428`
- Longitude: `36.67102154233`

The map uses Mapbox Standard Satellite, globe projection, 3D terrain, a two-stage fly-in animation, and a direct Google Maps link.
